# 휴대폰으로 앱 접속하기 (안드로이드·아이폰)

PC에서 백엔드와 앱(Expo)을 띄우고, 같은 와이파이에 있는 휴대폰의 **Expo Go**로 앱을 열어 백엔드를 부르는 방법이다. 시연도 이 방식으로 한다.

- 앱이 백엔드를 부르는 코드는 [PR #71](https://github.com/polopy07/jeonse_companion/pull/71)이다. 병합 전에는 `feature/frontend-api-connect` 브랜치에서 한다
- 서버 주소(`EXPO_PUBLIC_API_URL`)를 비워 두면 앱은 서버를 부르지 않고 시연 데이터·앱 안 임시 계산으로 동작한다
- 명령은 Windows PowerShell 기준이다. macOS는 아래 "macOS" 줄을 쓴다

## 한 번만 준비

| 할 일 | 방법 |
| --- | --- |
| Python 패키지 | `cd backend; pip install -r requirements.txt` |
| Node.js | LTS 버전. `cd frontend; npm ci` (`npm install`은 npm 버전에 따라 `package-lock.json`을 고쳐 커밋 거리가 생김) |
| 공공데이터 인증키 (실거래가를 쓸 때만) | `backend/.env.example`을 `backend/.env`로 복사해 채움 (git 제외) |
| 휴대폰 앱 | 안드로이드는 Play 스토어, 아이폰은 App Store에서 **Expo Go** 설치 |

## 1. 백엔드 띄우기

DB 설치 없이 SQLite로 띄운다. `--host 0.0.0.0`이 있어야 휴대폰에서 접속된다.

```powershell
cd backend; $env:DATABASE_URL="sqlite:///./jeonse.db"; python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --env-file .env
```

- macOS: `cd backend && DATABASE_URL=sqlite:///./jeonse.db python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --env-file .env`
- `uvicorn`만 치면 "인식되지 않습니다"가 나올 수 있다(설치는 됐지만 PATH에 없음). `python -m uvicorn`으로 띄운다
- `backend/.env`가 없으면 `--env-file .env`를 뺀다
- 처음 띄울 때 Windows 방화벽 창이 뜨면 **개인 네트워크 허용**
- `Uvicorn running on http://0.0.0.0:8000`이 보이면 이 창은 닫지 않고 둔다

## 2. PC 주소를 앱에 넣기

1. PowerShell에서 `ipconfig` → Wi-Fi의 **IPv4 주소** 확인 (예: `192.168.0.10`). macOS는 `ipconfig getifaddr en0`
2. `frontend/.env.local` 파일을 만든다 (`.env.example`을 복사하거나 저장소 폴더에서 아래 한 줄. git에 올라가지 않음)

```powershell
Set-Content -Encoding utf8 -Path frontend\.env.local -Value "EXPO_PUBLIC_API_URL=http://192.168.0.10:8000"
```

휴대폰에서 `localhost`는 휴대폰 자신이라 PC의 IPv4 주소를 넣어야 한다.

## 3. 휴대폰에서 서버가 보이는지 확인

휴대폰 브라우저(안드로이드 Chrome, 아이폰 Safari)로 `http://<PC IP>:8000/health`를 연다. 응답이 오고 백엔드 창에 `GET /health ... 200 OK`가 찍히면 된다.

- 끝에 `/health` 없이 열면 `404 Not Found`가 나온다. 서버에 `/` 페이지가 없어서이고, 휴대폰 주소(예: `172.30.1.5`)가 로그에 찍혔다면 연결은 된 것이다
- 안 열리면 아래 "안 될 때"

## 4. 앱 띄우기

백엔드 창은 두고 새 PowerShell 창에서:

```powershell
cd frontend; npx expo start -c
```

터미널에 QR이 나온다. `.env.local`을 바꿨으면 꼭 `-c`로 다시 띄운다 (`EXPO_PUBLIC_` 값은 번들에 들어가 있음).

### 안드로이드

1. **Expo Go 앱을 열고** "Scan QR code"로 QR을 찍는다 (기본 카메라로는 안 열릴 수 있음)
2. 처음 열 때 번들을 받느라 조금 걸린다

### 아이폰

0. 아이폰 Expo Go는 **PC의 Expo CLI와 같은 Expo 계정으로 로그인**해야 프로젝트가 열린다 (안 하면 "You need to be signed in to Expo Go and Expo CLI"). 계정은 expo.dev에서 무료로 만들고, PC에서 `cd frontend; npx expo login`, 아이폰 Expo Go 앱에서도 같은 계정으로 로그인한 뒤 `npx expo start -c`를 다시 띄운다
1. **기본 카메라 앱**으로 QR을 찍고 "Expo Go에서 열기"를 누른다
2. Expo Go가 **"로컬 네트워크의 기기를 찾도록 허용"**을 물으면 **허용**. 거절했으면 설정 → Expo Go → **로컬 네트워크** 켜기 (꺼져 있으면 PC 서버에 연결되지 않음)

## 5. 서버와 연결됐는지 확인

1. 홈 → **새 집 계약 전 확인** → **시연 집으로 채우기** → 결과 보기. 백엔드 창에 `POST /api/checks ... 200`이 찍히면 연결된 것
2. 결과 화면에 "서버에 연결하지 못해 앱에서 임시로 계산했어요"가 보이면 앱은 열렸지만 서버에 닿지 못한 것 → 2·3번 다시 확인
3. 계약 당일 체크 → 특약 **거절당함** → 날짜 입력 → 할 일 탭에 할 일 9개가 서버 순서대로 나오면 계약 생성까지 연결된 것 (빌라는 전입신고가 맨 위)

등기부 PDF를 시험하려면 PDF를 휴대폰에 먼저 저장해 둔다. 안드로이드는 다운로드 폴더, 아이폰은 **파일** 앱(iCloud Drive 또는 "나의 iPhone"). "등기부 PDF 고르기"에서 고르면 백엔드 창에 `POST /api/registry/parse`가 찍힌다.

## 시연 전 DB 초기화

리허설·시연 직전에는 테스트로 만든 판정·계약을 지우고 시연 상태로 되돌린다 ([PR #76](https://github.com/polopy07/jeonse_companion/pull/76)).

1. 백엔드 서버를 끈다 (`Ctrl+C`)
2. 같은 창에서 (`DATABASE_URL`이 서버와 같아야 함):

```powershell
cd backend; $env:DATABASE_URL="sqlite:///./jeonse.db"; python reset_demo_db.py
```

3. `y`를 누르면 모든 표를 다시 만들고 실거래 저장본(기준일 2026-10-13, 180건)을 넣는다
4. 서버를 다시 켠다. 휴대폰 앱에 남은 예전 계약은 서버에 없으면 앱이 지운다

## 안 될 때

| 증상 | 확인할 것 |
| --- | --- |
| 휴대폰에서 `/health`가 안 열림 | PC와 휴대폰이 같은 와이파이인지. 학교·카페 와이파이는 기기끼리 연결을 막는 경우가 많다 → 휴대폰 **핫스팟**에 PC를 연결하고 PC 주소를 다시 확인(아이폰 핫스팟은 보통 `172.20.10.x`)해 `.env.local`을 고친 뒤 `npx expo start -c` |
| 같은 와이파이인데도 안 열림 | Windows 방화벽에서 Python(8000번 포트) 허용, 백엔드를 `--host 0.0.0.0`으로 띄웠는지 |
| QR을 찍어도 앱이 안 열림 | `npx expo start --tunnel`로 띄운다. 앱은 열리지만 백엔드는 여전히 같은 네트워크여야 한다 |
| 아이폰에서 "You need to be signed in to Expo Go and Expo CLI" | PC `npx expo login`과 아이폰 Expo Go 로그인을 같은 계정으로 하고 `npx expo start -c` 후 다시 QR. 로그인하면 Expo Go 첫 화면 "Development servers"에도 프로젝트가 보인다 |
| "incompatible SDK" 같은 버전 오류 | 스토어의 Expo Go는 최신 Expo SDK 하나만 지원한다. 이 프로젝트는 SDK 57(`frontend/package.json`). Expo Go 버전과 다르면 SDK를 맞춰야 한다 |
| 와이파이를 바꾼 뒤 연결 안 됨 | PC 주소가 바뀐다. `ipconfig`로 다시 확인해 `.env.local`을 고치고 `npx expo start -c` |
| 서버 오류(422·409 등)가 화면에 나옴 | 서버가 답한 오류라 연결은 된 것. 문구를 보고 입력을 고친다 (같은 판정으로 계약을 두 번 만들면 409 `CHECK_ALREADY_USED`) |
| 할 일이 예전 계약으로 나옴 | 앱이 마지막 계약 id를 휴대폰에 저장해 다시 불러온다. 로컬 DB(`backend/jeonse.db`)를 지우면 다음 실행 때 저장한 id도 지워진다 |
