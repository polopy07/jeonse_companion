# 4주 개발 계획 (MVP)

기획서 v4.35의 4주 개발 계획을 주차·담당별로 풀어 쓴 계획이다. 요구사항 ID는 요구사항 명세서 v0.5 기준.

- **특약 반영 분기 2개** (FR-050) → 개발 A 3주차
- **계약 당일 체크 화면 UI-03** (FR-047, FR-049) → 개발 B 2주차
- **실거래가 API 연동·주변 시세** (FR-004, FR-046) → 개발 A 2주차. 시연 집이 있는 구의 아파트·연립다세대 최근 12개월을 공공데이터포털 API로 받아 저장하고, 시연·검증은 저장본으로 한다
- **계약 생성 API·할 일 9종 생성** (FR-014, 015, 017~020) → 개발 A 2주차 (10/12에 3주차에서 앞당김)
- **계약 조건·특약 변경 → 할 일 재계산** (FR-021, 049·050) → 개발 A 2주차 (10/14에 3주차에서 앞당김). 할 일 화면에서 날짜·특약을 고치는 시연 장면에 필요
- 사용자 인터뷰는 하지 않는다. 검증은 등기부 추출·기한 계산·경보 계산 3개와 4주차 사용성 테스트로 한다.

## 역할

| 구분 | 담당 | 맡는 일 |
| --- | --- | --- |
| PO + 개발 A (백엔드·규칙) | 황웅재 | 기능 우선순위·백로그, 판정 기준·연동 규칙·할 일 9종·특약 반영 분기·현장 확인 목록 명세, 특약 예시 문구·출처, 검증 기준(등기부 샘플, 기한·경보 정답표), 범위 축소 결정 / 등기부 파싱·재비교, 판정·연동 규칙, 특약 분기, 할 일 엔진, 갈아타기 계산, 실거래가 API 연동, 경보 계산, LLM 설명, 이메일 발송, 가상 날짜 계산, 배포 |
| PM + 개발 B (프론트·검증) | 배승환 | 일정·범위·리스크, 검증 지표, 공공데이터 API 키 신청, LLM·이메일 비용 측정, 경쟁 서비스 조사, 시연 데이터 준비, 시연 시나리오·발표 자료 / 화면(동작 5개·정적 4개), 기록함, 알림(앱 안 기한표·ICS), 가상 날짜 전환, 개인정보 동의·면책 문구, 사용성 테스트 |

4주 이후 출시 준비(서버·도메인·HTTPS, 증빙 파일 암호화 저장·백업, 보증기관 요건과 법률 자문, B2G 제안)는 함께 맡는다.
