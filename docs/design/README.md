# 화면 목업 (UI-01~09)

요구사항 명세서 v0.4 6.1절 "주요 화면 목록"의 9개 화면과 홈 화면을 모바일(폭 390px) 목업으로 그린 것이다. 시연 시나리오(부산 근저당 빌라, 담보 설정 금지 특약 "거절당함")를 그대로 따라간다. 프론트(React PWA)를 만들 때 이 목업을 화면·문구·색의 기준으로 삼는다.

## 보는 방법

- `index.html`을 브라우저로 열면 10개 화면이 한 페이지에 모여 보인다. 화면 이름을 누르면 크게 열린다.
- 화면끼리 버튼·하단 탭이 링크로 이어져 있어 흐름을 따라갈 수 있다.
- UI-03(특약 넣음/거절당함), UI-05(평소/비상)는 눌러서 바뀌는 모습을 볼 수 있다.
- `preview.js`는 목업을 그리기 위한 최소 스크립트다. 앱 코드에 가져다 쓰지 않는다.

## 디자인 규칙

- **폰트**: IBM Plex Sans KR (Google Fonts) 400·500·600·700
- **색**
  - 바탕 `#F4F2EC`, 카드 `#FFFFFF`, 카드 테두리 `#E3DFD6`
  - 글자 `#17202A`, 보조 글자 `#55606B`, 작은 안내 `#6B7580`
  - 주 색(버튼·선택·진행) `#1D3B5C`
  - 판정·경보 색은 이 셋에만 강하게 쓴다
    - 문제 항목·비상: 글자 `#A61B1B` / 배경 `#F6E3E3`
    - 확인 필요·주의: 글자 `#8A4307`, 강조 `#B85A0B` / 배경 `#FBEEDF`
    - 문제 없음·완료: `#2B5C8A`
- **모서리**: 큰 카드 16~18px, 작은 카드 12~14px, 버튼 10~14px
- **터치 영역**: 버튼·링크 높이 44px 이상, 주 버튼 52px
- **아이콘**: 선 굵기 1.8의 단순한 선 아이콘. 이모지와 기관 로고는 쓰지 않는다.
- **판정 표시**: 색만으로 구분하지 않고 아이콘과 글자(문제 항목 / 확인 필요 / 문제 항목 없음)를 같이 쓴다. "안전합니다"는 쓰지 않는다.
- **확인 못 한 항목**: 판정과 상관없이 점선 테두리 박스로 항상 보인다.
- **하단 고지**: 모든 결과 화면 맨 아래에 조회 시점과 "정보 제공이며 보증하지 않습니다"를 둔다.

## 화면 구조

- 하단 탭 4개: 홈 / 할 일 / 기록함 / 경보. 계약 전 확인(무료)은 탭 없이 들어가는 흐름이다.
- 홈은 "지금 할 일" 1개만 크게 보여 주고, 보증금 비율과 기록함 현황을 작은 카드로 둔다.
- 할 일은 세로 타임라인에 오늘 선을 긋는다. 완료 버튼은 증빙 사진 1장을 남기는 카메라 버튼이다.
- 기록함은 서류 칸 9개를 격자로 보여 주고, 비상 모드에서는 청구에 필요한데 빠진 서류만 빨간 칸으로 표시한다.

## 예시 값

화면의 숫자는 백엔드 계산식에 맞춘 예시다. 보증금 1억 4,000만 원, 근저당 3,600만 원, 공시가격 1억 5,000만 원 → 추정 집값 2억 1,000만 원 → 내 보증금 비율 84%. UI-09 경보 추이(84% → 88% → 91%)는 시연용 가상 값이다. 반환보증 가입 마감일은 `rules/guarantors.yaml` 값이 정해지면 채운다.
