# 시연 집 2채 경보 계산 정답표

> **상태: 시연 집 확정 (2026-10-13).** 4주차에 경보 계산 결과와 이 표를 대조한다 (NFR-004, 기획서 v4.35 검증 계획 "경보 계산이 맞는가"). 모두 일치해야 통과이고, 안 맞으면 계산 규칙을 고친다.

- 근거: 규칙 파일 `rules/alert.yaml`(추정 주택가격·내 보증금 비율·주변 전세 시세·경보 단계), `rules/verdict.yaml`(판정), 명세서 v0.5 FR-002~004·036·046
- 기계가 읽는 형식은 [`demo_houses.yaml`](demo_houses.yaml), 실거래 저장본은 [`demo_trades_2026-10-13.json`](demo_trades_2026-10-13.json) (2개 단지 180건)
- 기준일은 **2026-10-13**으로 고정한다. 실거래는 이날 공공데이터포털에서 받은 것이고, 시연·검증은 이 저장본으로 한다. 다시 받으면 새 거래가 붙어 값이 바뀔 수 있다
- 아래 값은 손으로 계산하고, 실거래 연동(#35)·등기부 파서(#62) 코드로 같은 입력을 넣어 판정·경보가 같게 나오는 것을 확인했다

## 계산 약속

| 번호 | 약속 | 근거 |
| --- | --- | --- |
| A1 | 추정 주택가격 = 공시가격 × 140%. 같은 단지·비슷한 면적의 매매 실거래가가 있으면 둘 중 낮은 값 | alert.yaml `estimated_price` |
| A2 | 매매 실거래가는 기준일 포함 이전 12개월, 전용면적 ±10%, 해제 신고 제외, 가장 최근 거래(같은 날이면 낮은 값) | alert.yaml v1.1 |
| A3 | 연립다세대는 단지 이름이 같아도 지번이 같아야 같은 단지 | `app/engine/market.py` |
| A4 | 내 보증금 비율 = (보증금 + 근저당 채권최고액 합계) ÷ 추정 주택가격 | alert.yaml `deposit_ratio` |
| A5 | 주변 전세 시세 = 같은 단지·전용면적 ±10%·12개월 전세(월세 0) 중앙값. 갱신 계약 제외, 3건 미만이면 표본 부족 | alert.yaml `nearby_jeonse` |
| A6 | 경보: 주의 = 비율 80% 이상 또는 주변 전세 < 내 보증금, 경고 = 90% 이상, 위험 = 100% 이상 | alert.yaml `levels` |

## 시연 집

| | 아파트 | 빌라 |
| --- | --- | --- |
| 단지 | 해운대구 세실로 7 (좌동 1331 해운대상록아파트), 2~3층 세대 | 수영구 무학로52번길 36-11 (광안동 129-46 제이제이) |
| 전용면적 | 59.85㎡ | 30.03㎡ |
| 공시가격 (2026.1.1) | 1억 6,500만 | 1억 1,600만 |
| 등기부 (부동산정보요약) | 단독소유, 갑구·을구 기록사항 없음 | 단독소유, 갑구 기록사항 없음, **을구 근저당 1,440만 (시연용 가상)** |
| 시연 보증금 | 2억 | 1억 4,000만 |

빌라 근저당은 실제가 아니다. 제이제이 30.03㎡ 세대 3곳을 열람했더니 모두 근저당이 없었고(건물 전체 근저당 → 2024 임의경매 → 2026.4 호별 매각), 근저당이 있는 실제 집 2곳(근저당 9,020만인 아파트, 3억 3,150만인 구축 빌라)은 시세 보증금을 넣으면 비율이 100%를 넘어 "문제 항목"으로 결제 전에 멈춘다. 담보 설정 금지 특약은 근저당이 있어야 나오고(`special_terms.yaml` `shown_when: [L-MORTGAGE]`), 보증 거절 시 해제 특약은 비율 90% 이상이어야 나오므로, 실제 단지·공시가격·실거래 위에 근저당 1건만 더했다. 화면과 시연 자료에 "시연용 가상 근저당"으로 표시한다.

## 계산

| 단계 | 아파트 | 빌라 |
| --- | --- | --- |
| 공시가격 × 140% | 1억 6,500만 × 1.4 = **2억 3,100만** | 1억 1,600만 × 1.4 = **1억 6,240만** |
| 매매 실거래가 (A2) | 3억 (2026-10-03, 59.85㎡, 12개월 48건) | 2억 5,000만 (2026-09-30, 30.09㎡, 12개월 14건) |
| 추정 주택가격 (A1) | **2억 3,100만** (실거래가 더 높아 쓰지 않음) | **1억 6,240만** (실거래가 더 높아 쓰지 않음) |
| 근저당 채권최고액 | 0 | 1,440만 |
| 내 보증금 비율 (A4) | 2억 ÷ 2억 3,100만 = **86.6%** | (1억 4,000만 + 1,440만) ÷ 1억 6,240만 = **95.1%** (근저당이 없으면 86.2%) |
| 주변 전세 시세 (A5) | 중앙값 **1억 9,000만** (39건) → 내 보증금보다 낮음 | 중앙값 **1억 4,500만** (17건) → 내 보증금보다 높음 |
| 판정 | **문제 항목 없음** (확인 못 한 항목: 임대인 국세·지방세 체납) | **확인 필요**: C-1 근저당 있음, C-2 비율 90% 이상 |
| 연동 규칙 | 없음 | L-MORTGAGE, L-RATIO90 |
| 경보 (A6) | **주의** (80% 이상, 주변 전세 < 보증금 두 조건 모두) | **경고** (90% 이상) |

두 단지 모두 최근 매매가가 공시가격 × 140%보다 높아 추정 주택가격은 공시가격으로 정해진다. 실거래는 주변 전세 시세(아파트 "주의"의 두 번째 조건)와 근거 표시에 쓰인다.

## 계약 당일 장면 (빌라)

S7과 같은 날짜(계약 2026-10-14, 잔금 2026-11-25, 만기 2028-11-24)에 담보 설정 금지 "거절당함", 보증 거절 시 해제 "넣음"을 고르면:

- 4번 전입신고가 목록 맨 위 (담보 설정 금지 거절)
- 2번 보증기관 상담 기한 = 계약일 2026-10-14 (L-RATIO90)
- 3번 잔금일 재비교에 "근저당 금액 변동 비교 (필수)" (L-MORTGAGE)
- 계약 시작 경보 단계 "경고"
