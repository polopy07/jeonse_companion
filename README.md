# 전동기 (전세동행기록)

> 계약할 때 한 번 보는 서비스가 아니라, 전세 사는 내내, 다음 집까지 같이 가는 서비스.

**전동기**는 전세 계약 전부터 보증금을 돌려받고 다음 집으로 옮길 때까지, 내 계약에 맞는 할 일을 챙기고, 그 과정을 모두 기록하고, 내 보증금의 위험을 계속 지켜보는 전세 세입자용 서비스입니다. 2인 학과 프로젝트로 진행하고 있습니다.

## 해결하려는 문제

1. **할 일이 사람마다 다르고 서로 연결돼 있다.** 대출 여부, 보증기관, 신고 대상 여부, 점검 결과, 계약서에 넣은 특약에 따라 할 일이 달라지고, 잔금일이 밀리면 뒤 기한도 밀립니다. 2년 뒤에는 지금 집 보증금 반환과 다음 집 잔금을 맞춰야 합니다.
2. **보증금을 못 돌려받는 순간에야 서류를 찾는다.** 반환보증 청구와 임차권등기명령 모두 계약 기간 동안 모아 둔 서류가 필요합니다.
3. **정보 비대칭.** 계약 전에는 집값에 비해 내 보증금이 얼마나 위험한지 알기 어렵고, 계약 후에는 집값이 떨어져도 알려 주는 곳이 없습니다.

## 주요 기능

| 구분 | 기능 | 하는 일 |
| --- | --- | --- |
| 메인 ① | 맞춤 할 일 | 점검 결과, 계약서에 실제로 넣은 특약, 내 계약 날짜·조건으로 할 일 9종과 기한을 만들고, 만기 때 다음 집 계약까지 이어서 관리(갈아타기) |
| 메인 ② | 전세 기록함 | 할 일을 완료할 때 증빙 사진 1장을 남겨 서류가 자동으로 쌓임. 평소엔 계약 기록, 보증금을 못 받으면 빠진 청구 서류를 바로 보여 주는 비상 서류함 |
| 메인 ③ | 역전세 경보 | 계약 전에는 주소와 보증금만으로 내 보증금 비율을 무료로 확인하고, 계약 중에는 공시가격·실거래가가 바뀔 때마다 다시 계산해 위험이 커지면 알림 |
| 보조 | 사전 권리 점검 | 등기부 "주요 등기사항 요약" 페이지 해석, 위반건축물 확인 |
| 보조 | 계약 당일 체크 | 현장 확인(소유자·대리인·계좌 명의), 공공 자료 특약 예시, 특약 "넣음 / 거절당함" 기록 → 2년 할 일 시작 |
| 보조 | 알림·캘린더 | 이메일, 앱 안 기한표, 구글·애플 캘린더(ICS) |

점검 결과는 **문제 항목**(결제 전 멈춤) / **확인 필요**(특약 넣고 진행) / **문제 항목 없음**으로 판정합니다. 다가구·단독주택은 점검·경보 대상이 아니어서 할 일 관리만 제공합니다. 모든 결과는 판정이 아닌 정보로 표시하며, 개별 법률 판단이나 대출·보증 상품 추천은 하지 않습니다.

## 사용자 흐름

```
계약 전 (무료)              계약 당일                  계약 ~ 입주              거주 · 만기 · 다음 집
주소·보증금 → 경보 지표  →  현장 확인 → 특약 예시   →  신고 · 보증 가입     →  경보 재계산 · 만기 통보
등기부 요약 → 판정           특약 넣음/거절당함 기록     잔금일 재비교 · 전입      반환 확인 → 갈아타기
                             날짜 입력 → 할 일 생성                               (못 받으면 반환 대응)
```

## 대상과 수익 모델

- **대상**: 전세 계약을 앞두거나 전세로 살고 있는 세입자. 첫 공략 고객은 **부산 20~30대 첫 전세 세입자**이며, 부산에서 검증한 뒤 수도권으로 넓힙니다.
- **수익 모델**

| 상품 | 내용 | 가격(가설) |
| --- | --- | --- |
| 계약 전 확인 | 내 보증금 비율, 등기부 요약 해석, 위반건축물 확인 | 무료 |
| 전동기 패키지 | 계약 당일 체크, 맞춤 할 일, 전세 기록함, 계약 중 경보 (계약 1건, 만기 후 3개월까지) | 9,900원 (다가구·단독 할 일 관리만 4,900원) |
| 기관 이용권 (B2G) | 지자체·공공기관·대학이 일괄 구매해 대상자에게 배포 | 1장 9,900원 기준 |

## MVP 범위

- **기간·인원**: 4주, 2인
- **시연**: 부산 집 2채(근저당 있는 다세대 빌라, 아파트)로 계약 전 확인 → 판정 → 계약 당일 체크 → 맞춤 할 일 → 기록함 → 만기·갈아타기를 가상 날짜로 5분 안에 시연. 빌라의 담보 설정 금지 특약을 "거절당함"으로 골라 할 일 순서가 바뀌는 장면을 보여 줌
- **화면**: 동작 화면 5개(계약 전 확인, 계약 당일 체크, 할 일 목록, 기록함 업로드, 갈아타기 입력) + 정적 화면 4개(판정 상세, 계약 타임라인, 반환 대응 안내, 경보 리포트)
- **제외**: 실제 결제(테스트 모드만), 계약서 OCR, 주민번호 자동 가림, 공유 링크, 웹 푸시, 다가구 점검

## 기술 스택 (제안)

| 영역 | 기술 |
| --- | --- |
| 프론트엔드 | React 기반 모바일 웹(PWA) |
| 백엔드 | Python FastAPI, PostgreSQL |
| 등기부 처리 | pdfplumber + "주요 등기사항 요약" 페이지 규칙 기반 파서 |
| 할 일 엔진 | 규칙 기반 (기한 계산은 LLM이 아닌 규칙으로 처리) |
| 알림 | 이메일 + APScheduler, ICS 파일 생성 |
| AI | LLM API (등기부 쉬운 말 설명, 할 일 안내 문구) |
| 공공 데이터 | 공동주택 공시가격, 건축물대장, 국토교통부 실거래가 |
